# Moondream

> Moondream is a fast, efficient open vision language model (VLM) from M87 Labs. The Moondream Cloud API exposes the model's "Skills" — visual question answering (Query), Captioning, object Detection, Pointing, and Segmentation — plus an OpenAI-compatible chat endpoint. Weights are open and downloadable from Hugging Face; hosted inference, batch processing, and finetuning (Lens) run in Moondream Cloud. This llms.txt was generated by API Evangelist from the public Moondream documentation.

## API

- [Moondream Cloud API](https://api.moondream.ai/v1): Base URL for all Skill endpoints (/query, /caption, /detect, /point, /segment) and the OpenAI-compatible /chat/completions endpoint. Auth via X-Moondream-Auth header (Skills) or Bearer token (chat).
- [API Reference](https://docs.moondream.ai/api): Endpoint reference with request/response examples.
- [Getting Started](https://docs.moondream.ai/quickstart): Grab a key and make a first call.
- [OpenAI Compatibility](https://docs.moondream.ai/openai): Point any OpenAI client at Moondream.
- [Streaming](https://docs.moondream.ai/streaming): Token-by-token responses for query, caption, segment.
- [Batch API](https://docs.moondream.ai/batch): Asynchronous JSONL bulk processing at 50% pricing.
- [Rate Limits](https://docs.moondream.ai/rate-limits): 2 req/sec base, 10 req/sec funded accounts.
- [Finetuning (Lens)](https://docs.moondream.ai/finetuning): RL/SFT finetuning in Moondream Cloud.
